This is a simple To-Do software made in C++.<br>
The data file is compatible with SbitW/todo-go-cui.<br>
Run build.sh(This expects g++) to build the software.<br>
Usages are the same with SbitW/todo-go-cui, expect 'todo' should be 'cptodo' if you used the default build.sh.<br>
This software uses github.com/nlohmann/json.<br>
The display language is currently Japanese only.<br>
